# Security Policy

MCP Server for Joomla gives AI assistants access to your site with the permissions of the connected user. Please report security problems privately so they can be fixed before they are published.

**Do not open a public issue for a vulnerability.** Use GitHub's private vulnerability reporting instead: on this repository, open the **Security** tab and choose **Report a vulnerability**.

Please include the version, your Joomla and PHP versions, and steps to reproduce. You will get a response within a week.

## Supported versions

Only the latest release receives security fixes.
